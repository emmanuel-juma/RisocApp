## About the Project

ResocApp is a web-based learning and research platform designed to help students and researchers find educational resources in one place. Users can search for books and educational videos to support their learning and research.

The application provides a simple and user-friendly interface that makes discovering learning materials easier.

# Features


- Book Search: Find books using the Open Library API.
- YouTube Videos: Discover educational videos using the YouTube Data API.
- Responsive Design: Browse the application on desktop and mobile devices.
- Blog Section: Read articles about studying, artificial intelligence, reading, and technology.
- Navigation: Move between the welcome page, login page, and resource search page.

# Technologies Used

- HTML5 — webpage structure.
- CSS3 — styling and responsive design.
- JavaScript — page navigation, form handling, and API integration.
- Open Library API — book search.
- YouTube Data API v3 — educational video search.
